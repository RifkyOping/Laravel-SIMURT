# Workflow: Mulai Increment
Gunakan: `/mulai-increment` lalu sebutkan nomor increment (1-4).

1. Baca AGENTS.md dan semua rule di `.agents/rules/`. Identifikasi cakupan increment yang diminta (lihat daftar di AGENTS.md).
2. Buat Implementation Plan: file yang akan dibuat/diubah, migration & relasi, route, controller/Form Request/service/policy, view & JS (rujuk rule 04-06), seeder, daftar feature test. Sebutkan asumsi (rule 07).
3. BERHENTI dan minta persetujuan saya sebelum menulis kode.
4. Setelah disetujui: kerjakan, jalankan migration/seeder/test, perbaiki error sampai lulus.
5. Berikan ringkasan: apa yang selesai, cara menjalankan di Laragon, skenario uji manual, dan hal yang perlu keputusan saya.
6. Jangan lanjut ke increment berikutnya sebelum saya menyatakan increment ini selesai.
